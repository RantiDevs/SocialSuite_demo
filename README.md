# Social Suite Pro - Frontend Demo

This is a standalone, frontend-only demo of the Social Suite Pro platform.

## 🚀 Deployment (Vercel)
This folder is pre-configured for Vercel. 
1. Push this folder to a GitHub repo.
2. Link the repo to Vercel.
3. Vercel will automatically detect the settings and deploy.

## 💻 Local Development
1. `npm install`
2. `npm run dev`

## 🛠 Features in this Demo
- **Mocked API**: All data fetching is redirected to a local mock data file (`src/lib/mock-data.ts`).
- **3D Universe Background**: Full Three.js starfield integration.
- **Bypassed Auth**: Jump straight into the dashboard with a mock "Admin" account.
- **Infinite Marquee**: The landing page features a never-ending scrolling carousel.
